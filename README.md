Entry for the make.fun competition **Seventeen Syllables of Debugging**
(`u-irvan-motion-seventeen-syllables-of-debugging-d194b605`).

`main.ts` (Node 22, standard library only, no network) writes one haiku
about debugging — three lines in the 5-7-5 syllable shape, at most 200
characters — to `/output/entry.txt` (or `$ENTRY_OUTPUT_PATH` when set).
The text is validated before writing: 1–200 Unicode characters, not only
whitespace, exactly 3 non-empty lines.

> Cursor blinks at three
> one more log line lies again
> so the bug was me

Run it with:

```sh
node main.ts
```
